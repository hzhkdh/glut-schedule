# 我要开发一个 Android 课表 App，最终可以打包成 APK。

核心目标：
做一个极简课表 App，一打开就是课表页面，不要登录注册模块，不要社区、搜题、广告、资讯等无关功能。

功能要求：
1. 不需要登录注册模块。
2. App 支持从桂林理工大学教务系统读取学生个人课表。
   教务相关地址：
   - http://jw.glut.edu.cn/academic/manager/coursearrange/showTimetable.do?id=712170&yearid=46&termid=1&timetableType=STUDENT&sectionType=BASE
   - http://jw.glut.edu.cn/academic/preGotoAffairFrame.do#/menu
3. 注意：同一个班级内，不同学生课表可能不同，因为存在重修课、选修课、个人选课差异，所以必须读取“学生个人课表”，不能只按班级课表处理。
4. App 应提供“从教务导入课表”按钮，点击后打开校内教务页面。用户自行登录教务系统，登录成功后 App 尝试读取当前学生个人课表数据。
5. 不要在代码中硬编码我的账号密码。
6. 如果教务系统需要 Cookie / Session，请用 WebView 登录后保存 Cookie，再请求课表页面。
7. 如果网页结构复杂，先实现一个可扩展的 parser 层，后续我会提供 HTML 文件或截图辅助你解析。
8. 首页课表布局参考 wakeup 课程表：
   - 左侧显示节次和上下课时间
   - 顶部显示周一到周日
   - 中间用彩色课程卡片展示课程
   - 卡片显示课程名、教室、教师、周次/备注等信息
9. 上下课时间使用雁山、屏风、南宁三套独立档案（屏风第一节 08:20），同时允许用户分别手动调整。
10. 支持左右滑动切换上一周 / 下一周，像日历一样。
11. 支持当前周显示，例如“第9周 周二 2026/5/5”。
12. 支持课程的添加、编辑、删除。
13. 支持课程调课：用户可以单独修改某一次课的时间、地点、备注，不影响整个课程。
14. 支持更新课表：再次连接教务系统时，可以重新拉取最新课表，并合并本地用户修改。
15. 支持自定义背景图片。
16. 默认背景使用梵高《星空》风格的柔和暗色背景，要求不能刺眼，不能影响课程卡片文字可读性。
17. 课程卡片参考截图样式：圆角、多颜色区分、半透明、高级液态毛玻璃效果，类似 Apple 风格。
18. 我会把参考图片放到项目的 images 文件夹里，请你读取并参考。
19. 本地数据保存使用 SQLite 或 Hive，优先推荐 Hive，保证离线可用。
20. 如果需要写 Python 辅助脚本解析 HTML，请用 conda 创建 scheduleApp 环境，所有 Python 依赖安装到该环境中。
21. 项目结构要清晰，至少包括：
   - models
   - pages
   - widgets
   - services
   - parsers
   - storage
   - assets/images
22. 请先完成项目基础架构、数据模型、首页课表 UI、周切换、本地模拟数据展示，不要第一步就接教务系统。
23. 每完成一个阶段，请告诉我执行什么命令验证。
24. 代码要能直接运行，不要只给伪代码。
25. 侧边栏副标题支持本地智能问候语：姓名、考试与学期数据只在本机组合，远程服务仅下发受限文案模板；设置页可通过“问候语”开关恢复静态品牌语。

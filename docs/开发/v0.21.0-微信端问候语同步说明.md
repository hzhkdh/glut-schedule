# v0.21.0 Android → 微信端问候语同步说明

## 目标

微信端后续同步 Android v0.21.0 的侧边栏问候语能力时，复用同一远程文案源和业务语义，避免两端形成不兼容的模板体系。

## 共享契约

- 远程文件：`https://update.999314.xyz/greetings.json`
- 格式版本：`schemaVersion = 1`
- 分类：`greeting`、`examToday`、`examTomorrow`、`examUpcoming`、`semesterWeek`、`semesterEnding`
- 占位符：`{name}`、`{period}`、`{course}`、`{days}`、`{week}`
- 今日尚未结束或明日有考试时，考试分类独占。
- 2～7 天内考试才进入普通混合池。
- 远程模板按分类覆盖；远程分类无有效内容时回退该端内置模板。
- 远程端只控制文案，不控制时间窗、权重、开关和动画。

## 微信端实现注意

- 姓名、课程、考试和学期数据必须在用户设备或微信端已有可信数据源中填充，不得上传到模板托管站点。
- 启动时读取本地有效缓存，并在缓存满 24 小时后后台刷新；网络失败不得阻塞页面或清空旧缓存。
- 每次打开对应侧边栏/菜单时生成新句子，避免连续重复。
- 动画可按小程序生命周期实现，但关闭系统动画或启用辅助功能时应直接显示完整句子。
- 设置项文案统一使用“问候语”；关闭后显示静态品牌语“简单 高效 纯粹”。

本说明只记录同步契约，Android v0.21.0 不修改微信端代码。

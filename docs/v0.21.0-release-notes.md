# v0.21.0 发布说明

**版本号**：0.21.0（versionCode 121）

**分支**：main

**发布日期**：2026-07-26

## 新增

- 侧边栏新增随机单句问候语，可结合教务姓名、近期考试、当前周次和学期进度。
- 今日与明日考试使用高优先级提醒，2～7 天内考试可进入普通随机池。
- 每次打开侧边栏刷新句子，并加入带 15 秒冷却的打字机效果。
- 设置页新增“问候语”开关，关闭后恢复“简单 高效 纯粹”。
- 支持 `greetings.json` 远程模板、24 小时缓存、分类覆盖和内置模板兜底。

## 隐私与兼容

- 姓名从既有教务个人信息响应提取，不新增教务请求。
- 姓名、课程和日期只在本机填充，不上传到模板服务。
- 远程模板不可控制考试规则、随机权重和动画参数。
- 已记录微信端后续同步分类、占位符和回退契约，本版本不修改微信端代码。
